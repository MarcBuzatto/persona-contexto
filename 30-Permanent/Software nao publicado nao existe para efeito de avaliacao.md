# Software nao publicado nao existe para efeito de avaliacao

Para quem avalia — banca, usuário, investidor — um produto que só roda na máquina de um integrante é indistinguível de um produto que não foi construído.

## Por quê

Deploy não é etapa de polimento no fim do cronograma: é o que converte trabalho em evidência. Sem URL pública não há teste com usuário, não há demonstração ao vivo e não há prova independente de capacidade de execução.

## Contraponto

Existe caso legítimo de não publicar: dado sensível real, custo proibitivo, obrigação contratual. Nenhum deles se aplica a um MVP de competição com camada gratuita.
